# ION Software Solutions

Professional single-page website for ION Software Solutions, built with HTML, CSS, and JavaScript.

## Project Structure

```text
ionsoftwaresolutions/
  index.html
  thank-you.html
  css/
    styles.css
  js/
    script.js
  assets/
    images/
    icons/
```

## Run Locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
